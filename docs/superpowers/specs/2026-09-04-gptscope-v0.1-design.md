# GPTScope v0.1 Design

## Purpose

GPTScope is a standalone clean-room inspector for authorized ChatGPT Desktop evidence. It normalizes user-supplied transcripts and JSONL events, redacts secrets before persistence, infers visible orchestration patterns (skills/instructions/tools/MCP/context/permission/surface), compares sessions, and exports implementation-neutral reports.

## Safety boundary

GPTScope does not bypass authentication, inspect process memory, extract credentials/cookies/tokens, defeat TLS/security controls, decompile proprietary binaries, or claim access to hidden prompts/source code. Findings are evidence-backed inferences from artifacts the user is authorized to inspect.

## V0.1 scope

- Node.js 22+ with no third-party runtime dependencies.
- Workspace directory with per-session metadata and JSONL event streams.
- Recursive redaction before persistence.
- Transcript and generic JSONL importers.
- ChatGPT surface classification: chat, work, codex, unknown.
- Deterministic inference for skill/instruction/tool/MCP/context/permission markers.
- Session comparison.
- Markdown + JSON export.
- CLI commands: init, session new/list, import transcript/jsonl, infer, compare, export, scan, doctor.
- Cross-platform CI on Ubuntu, Windows, macOS.

## Data model

A session is stored in `<workspace>/sessions/<session-id>/` with `session.json` and `events.jsonl`. Events are normalized to `{id, ts, kind, source, surface, text, payload}`. All strings and payload objects are redacted before write.

Inference produces `{sessionId, surface, summary, findings[]}`. Each finding carries `type`, `label`, `confidence`, and supporting `eventIds`; GPTScope never invents hidden prompt text or internal token counts.

## Error handling

Malformed JSONL lines fail closed with line-numbered errors. Unknown CLI commands return exit code 2. Missing workspaces/sessions/files return explicit errors without creating partial imports.

## Testing

Use `node:test`. Tests cover redaction, imports/persistence, deterministic inference, comparison/export, and CLI smoke behavior. CI runs `npm test` on Node 22 across three OSes.
