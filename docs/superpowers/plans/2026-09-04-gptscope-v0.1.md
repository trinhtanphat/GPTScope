# GPTScope v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a portable clean-room ChatGPT Desktop harness evidence inspector with deterministic redaction, import, inference, compare and export workflows.

**Architecture:** A dependency-free Node.js 22 ESM core persists per-session JSONL events under a workspace directory. Importers normalize authorized evidence; inference classifies visible ChatGPT orchestration markers; a thin CLI composes the core.

**Tech Stack:** Node.js 22 ESM, `node:test`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-04-gptscope-v0.1-design.md`

## Global Constraints

- Node.js 22+.
- No third-party runtime dependencies.
- Redact before persistence.
- Clean-room evidence only; no auth bypass, memory scraping, credential extraction, TLS defeat, decompilation, or hidden-prompt claims.
- Deterministic outputs for identical ordered events.
